# Logos HotteList

| Fichier | Usage |
|---|---|
| `hottelist-logo-noel.png` / `.svg` | Logo sur fond « ambiance Noël », format paysage 1600 × 900 (bannières, publications) |
| `hottelist-logo-noel-carre.png` / `.svg` | Même chose en carré 1080 × 1080 (Instagram, WhatsApp, Facebook) |
| `hottelist-partage.png` | 1200 × 630, aperçu affiché quand on partage un lien du site (aussi utilisé par le site) |
| `hottelist-logo.png` / `.svg` | Sans fond, couleurs sur fond clair (« Hotte » rouge, « List » vert sapin) |
| `hottelist-logo-blanc.png` / `.svg` | Sans fond, version pour fond sombre (« Hotte » crème, « List » or, cadeau jaune seul) |

L'icône est la hotte : sac de toile rouge, cadeau doré dessiné dessus avec une ombre floue, lien vert noué d'un rond doré.
Sur fond bordeaux, on ne met que le cadeau jaune (la hotte rouge s'y fondrait). Sur les autres fonds, le cadeau dans la hotte rouge. Les petites icônes (favicon, icônes d'application, notifications) : le cadeau sur un carré bordeaux.

Les SVG sont vectoriels : le texte est converti en tracés, ils s'affichent à l'identique partout et s'agrandissent sans perte.
Polices : Santa Natale (« Hotte », gratuite pour un usage personnel et non commercial), Fraunces italique 650 (« List »).
Couleurs : sac `#CF2B35`, cadeau `#FFD146`, lien `#3F7A52`, nœud `#FFCB2E`, bordeaux `#7E1621`, crème `#FFF9EE`, encre `#1F3A2C`.
Le dessin source de la hotte est le composant `src/components/brand.tsx`.
