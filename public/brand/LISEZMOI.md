# Logos HotteList

| Fichier | Usage |
|---|---|
| `hottelist-logo-noel.png` / `.svg` | Logo sur fond « ambiance Noël », format paysage 1600 × 900 (bannières, publications) |
| `hottelist-logo-noel-carre.png` / `.svg` | Même chose en carré 1080 × 1080 (Instagram, WhatsApp, Facebook) |
| `hottelist-partage.png` | 1200 × 630, aperçu affiché quand on partage un lien du site (aussi utilisé par le site) |
| `hottelist-logo.png` / `.svg` | Sans fond, couleurs sur fond clair (vert sapin + rouge) |
| `hottelist-logo-blanc.png` / `.svg` | Sans fond, version claire pour fond sombre (crème + or) |

L'icône est la tuile du favicon (bordeaux pointillé, cadeau doré), entourée d'un filet doré sur les fonds sombres.

Les SVG sont vectoriels : le texte est converti en tracés, ils s'affichent à l'identique partout et s'agrandissent sans perte.
Police : Fraunces italique 700 (« HotteList »), Inter 600 (accroche). Couleurs : bordeaux `#7E1621`, or `#F2C75C`, crème `#FFF9EE`, vert sapin `#1F4D36` / `#1F3A2C`, rouge `#B3202E`.
